## 通用约定

### 响应格式

```json
{
    "code": 0, // int, 0=成功, 非0=失败
    "msg": "success", // string
    "data": {} // 实际数据
}
```

### 分页响应

```json
{
    "code": 0,
    "msg": "success",
    "data": {
        "total": 100,
        "list": [],
        "pageNo": 1,
        "pageSize": 10
    }
}
```

### 分页查询参数

| 参数         | 类型   | 必填 | 说明               |
| ------------ | ------ | ---- | ------------------ |
| `pageNo`     | int    | 是   | 当前页码，默认1    |
| `pageSize`   | int    | 是   | 每页记录数，默认10 |
| `orderField` | String | 否   | 排序字段           |
| `order`      | String | 否   | asc/desc           |

### ID 类型

所有 ID 字段均为 **String 类型**（雪花算法，如 `"1734567890123456789"`）。

## 界面一：分包批次管理（核心流程页）

### 功能概述

这是系统的主要操作界面，用户在此上传分包数据、执行分包和推荐、导出结果。是整个业务流程的入口和操作中心。

### 调用的 API

#### 1. 查询批次列表（分页）

```
GET /api/subcontract/batch/page
权限: subcontract:batch:page
```

查询参数 (BatchQuery)：`batchNo`(模糊)、`flowNo`、`batchStatus`、`operator`

返回分页数据，每条 BatchVO 包含：
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 批次ID |
| batchNo | String | 批次编号 |
| flowNo | String | 委外流程编号 |
| batchStatus | String | DRAFT / DATA_READY / PACKAGED / RECOMMENDED / COMPLETED |
| uploadFileName | String | 上传文件名 |
| totalPartCount | Integer | 零件总数 |
| totalPackageCount | Integer | 工作包总数 |
| operator | String | 操作人 |

#### 2. 上传分包 Excel

```
POST /api/subcontract/batch/upload
权限: subcontract:batch:upload
Content-Type: multipart/form-data
```

参数：`file`(File, 必填)、`aircraftModel`(String, 选填, 默认机型如"zz")、`operator`(String, 选填)

返回 `Result<BatchImportResultVO>`：

```json
{
    "code": 0,
    "data": {
        "batchId": "1734567890123456789",
        "batchNo": "BATCH-20260722-001",
        "totalRows": 104,
        "successCount": 102,
        "errorCount": 2,
        "errors": [
            { "rowNo": 103, "message": "供应商需求数必须为正整数" },
            { "rowNo": 104, "message": "零件图号不能为空" }
        ]
    }
}
```

#### 3. 从全流程系统抓取数据

```
POST /api/subcontract/batch/fetch
权限: subcontract:batch:fetch
```

参数：`flowNo`(String, 必填)、`operator`(String, 选填)

返回：`Result<BatchImportResultVO>`（同上）

#### 4. 触发分包引擎

```
POST /api/subcontract/batch/{id}/package
权限: subcontract:batch:package
```

参数：`id`(String, 路径参数, 批次ID)

返回 `Result<List<PackageVO>>`，每条：

```json
{
    "id": "1734567890123456790",
    "batchId": "1734567890123456789",
    "packageNo": "zz-2607-001",
    "categoryId": "CAT-01",
    "supplierCountNeeded": 2,
    "recommendCount": 6,
    "partCount": 10,
    "partType": "中型",
    "maxPartLimit": 10,
    "hasHistorySupplier": 0,
    "isSpecialCategory": 0,
    "specialType": null,
    "recommendationStatus": null
}
```

#### 5. 触发供应商推荐引擎

```
POST /api/subcontract/batch/{id}/recommend
权限: subcontract:batch:recommend
```

参数：`id`(String, 路径参数, 批次ID)

返回 `Result<List<SupplierRecommendationVO>>`：

```json
{
    "id": "1734567890123456791",
    "packageId": "1734567890123456790",
    "batchId": "1734567890123456789",
    "supplierId": "SUP-A01",
    "supplierName": "供应商A01",
    "recommendOrder": 1,
    "recommendSource": "HISTORY",
    "qualityLevel": "优质",
    "performanceScore": 88.5
}
```

recommendSource 枚举：`HISTORY` / `QUALITY_ROUND` / `NORMAL_ROUND` / `ALL_CATEGORY`

#### 6. 一键编排

```
POST /api/subcontract/batch/{id}/run
权限: subcontract:batch:run
```

参数：`id`(String, 路径参数, 批次ID)

返回 `Result<OrchestrationResultVO>`：

```json
{
    "batchId": "1734567890123456789",
    "batchNo": "BATCH-20260722-001",
    "batchStatus": "COMPLETED",
    "packageCount": 15,
    "recommendationCount": 90
}
```

#### 7. 导出推荐结果 Excel

```
GET /api/subcontract/batch/{id}/export
权限: subcontract:batch:export-result
```

参数：`id`(String, 路径参数, 批次ID)

返回：Excel 文件流（浏览器自动下载）

#### 8. 批次 CRUD（增删改查）

```
GET    /api/subcontract/batch/{id}     → 查询单个
GET    /api/subcontract/batch/list     → 列表（不分页）
POST   /api/subcontract/batch          → 新增（body: BatchVO）→ Result<String> (新ID)
PUT    /api/subcontract/batch          → 修改（body: BatchVO）→ Result<Boolean>
DELETE /api/subcontract/batch/{id}     → 按ID删除 → Result<Boolean>
DELETE /api/subcontract/batch          → 批量删除（body: String[] ids）→ Result<Boolean>
```

### 界面需要的操作

1. **批次列表表格** - 展示所有批次，支持按批次编号、流程编号、状态、操作人筛选，支持分页
2. **上传 Excel 按钮** - 点击弹出文件选择器，选择分包Excel文件，可选填机型/操作人后上传
3. **抓取数据按钮** - 输入委外流程编号，从全流程系统拉取数据
4. **执行分包按钮** - 对选中批次（状态为 DATA_READY）触发分包引擎
5. **执行推荐按钮** - 对已分包批次的触发推荐引擎
6. **一键编排按钮** - 对选中批次一键执行：分包→推荐→回写
7. **导出 Excel 按钮** - 导出最终推荐结果清单
8. **批次状态流转展示**：DRAFT → DATA_READY → PACKAGED → RECOMMENDED → COMPLETED
9. **新建/编辑/删除批次** - 标准 CRUD 操作

### 状态说明

-   批次状态流转在界面上应有可视化展示（如步骤条/标签）
-   不同状态下的操作按钮应有可用/禁用状态控制

## 界面二：批次零件明细（数据查看页）

### 功能概述

查看某个批次下所有零件的详细信息，包括三级品类判定结果、零件类型、历史供应商等。用于数据追溯和校验。

### 调用的 API

#### 1. 分页查询

```
GET /api/part/batch-part/page
权限: part:batch-part:page
```

#### 2. 详情/列表/增删改

```
GET    /api/part/batch-part/{id}     → 查询单个
GET    /api/part/batch-part/list     → 列表（不分页）
POST   /api/part/batch-part          → 新增 → Result<String>
PUT    /api/part/batch-part          → 修改 → Result<Boolean>
DELETE /api/part/batch-part/{id}     → 按ID删除
DELETE /api/part/batch-part          → 批量删除
```

BatchPartVO 主要字段：
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 明细ID |
| batchId | String | 所属批次ID |
| seqNo | Integer | 序号 |
| partDrawingNo | String | 零件图号 |
| aircraftModel | String | 外协转码机型 |
| partName | String | 零件名称 |
| materialType | String | 材料类型 |
| lengthValue | BigDecimal | 长度 |
| widthValue | BigDecimal | 宽度 |
| nestingInfo | String | 套裁信息（分组关键字段） |
| historySupplier1~3 | String | 历史供应商 |
| supplierCountNeeded | Integer | 供应商需求数 |
| thirdCategory | String | 三级品类名称（上传值） |
| thirdCategoryId | String | 三级品类ID（系统推导） |
| partType | String | 零件类型：小型/中型/大型/超大型/其他 |
| packageId | String | 所属工作包ID（分包后回填） |
| packageNo | String | 分包号（回写） |
| recommendSupplier1~7 | String | 推荐供应商（导出回写） |

### 界面需要的操作

1. **零件明细表格** - 按批次维度查看零件列表，支持分页和筛选（按批次ID、零件图号、三级品类等）
2. **查看零件详情** - 点击查看单个零件的完整信息
3. **导出 Excel** - 导出当前查询结果
4. **导入 Excel** - 通用 CRUD 导入（正式上传应使用批次管理页的上传功能）

## 界面六：供应商绩效管理（绩效上传与查询页）

### 功能概述

用户每月上传供应商绩效 Excel 数据，系统自动计算半年平均和综合得分。

### 调用的 API

#### 1. 绩效 CRUD

```
GET    /api/supplier/performance/{id}     → 查询单个
GET    /api/supplier/performance/list     → 列表
GET    /api/supplier/performance/page     → 分页
POST   /api/supplier/performance          → 新增 → Result<String>
PUT    /api/supplier/performance          → 修改 → Result<Boolean>
DELETE /api/supplier/performance/{id}     → 按ID删除
DELETE /api/supplier/performance          → 批量删除
```

#### 2. 上传绩效 Excel（核心操作）

```
POST /api/supplier/performance/upload
权限: supplier:performance:upload
Content-Type: multipart/form-data
```

参数：`file`(File, 必填, Excel两列：供应商名称/绩效成绩)、`year`(Integer, 必填)、`month`(Integer, 必填)

返回 `Result<PerformanceUploadResultVO>`（含上传成功数、失败行等汇总信息）

PerformanceVO 字段：
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | ID |
| supplierId | String | 供应商ID |
| performanceYear | Integer | 年份 |
| performanceMonth | Integer | 月份 |
| score | BigDecimal | 原始成绩 |
| halfYearAvg | BigDecimal | 半年平均 |
| lastMonthScore | BigDecimal | 上月得分 |
| comprehensiveScore | BigDecimal | 综合得分 = 半年平均×0.6 + 上月×0.4 |

### 界面需要的操作

1. **绩效列表表格** - 展示各月绩效数据，支持按年份/月份/供应商筛选
2. **上传绩效按钮** - 选择 Excel 文件 + 选择年份和月份，上传后显示导入结果（成功/失败行）
3. **下载绩效模板** - 提供两列模板下载（供应商名称、绩效成绩）
4. **查看综合得分** - 表格中显示半年平均、上月得分、综合得分
5. **导入/导出 Excel**

#### 2. 生成排名快照（核心操作）

```
POST /api/supplier/ranking-snapshot/generate?year=2026&month=7
权限: supplier:ranking-snapshot:generate
```

参数：`year`(Integer, 必填)、`month`(Integer, 必填)

RankingSnapshotVO 字段：
| 字段 | 类型 | 说明 |

### 界面需要的操作

2. **生成排名按钮** - 选择年份和月份，点击生成排名快照
3. **按品类/年月筛选** - 关键筛选维度
4. **优质/普通标签展示** - 视觉区分
5. **导出 Excel**

## 业务操作流程总览

### 完整操作流程（界面设计需体现步骤引导）

```
步骤1: 数据准备
  ├─ [界面五] 维护供应商基础信息
  ├─ [界面九] 录入三级品类主数据（上线初始化）
  ├─ [界面十] 配置特殊品类规则
  ├─ [界面十四] 配置左右件识别规则
  └─ [界面十六] 确认工作包容量配置

步骤2: 绩效管理（每月）
  ├─ [界面六] 上传月度绩效 Excel
  └─ [界面七] 生成月度排名快照

步骤3: 分包操作（核心流程）
  ├─ [界面一] 上传分包 Excel 或抓取全流程数据
  ├─ [界面一] 触发分包引擎 → 生成工作包
  ├─ [界面一] 触发推荐引擎 → 生成推荐结果
  └─ [界面一] 导出推荐结果 Excel

步骤4: 结果查看与追溯
  ├─ [界面二] 查看批次零件明细
  ├─ [界面三] 查看工作包列表
  ├─ [界面十一] 查看推荐结果
  └─ [界面十七/十八] 查看操作日志
```

### 批次状态流转

```
DRAFT → DATA_READY → PACKAGED → RECOMMENDED → COMPLETED
 (初始)  (上传完成)   (分包完成)  (推荐完成)   (导出完成)
```

## 常用枚举值

| 枚举     | 可选值                                                               |
| -------- | -------------------------------------------------------------------- |
| 批次状态 | `DRAFT` / `DATA_READY` / `PACKAGED` / `RECOMMENDED` / `COMPLETED`    |
| 零件类型 | `小型` / `中型` / `大型` / `超大型` / `其他`                         |
